# 烤面筋 (sf-club-front)

> 现代化技术面试备战与高频真题刷题平台前端。

---

## 🌟 核心特性

- **📚 体系化题库**：涵盖 9 大技术职业通道与主流技术栈，支持多维度题目检索与沉浸式背题。
- **✍️ 全真考场**：支持跨分类自由组合出卷、多题型配比调节与沉浸式计时答题。
- **🤖 AI 模拟面试**：接入 AI 智能面试官，提供实时问答互动与多维度评估。
- **💬 技术圈子**：技术动态交流、求职经验分享与社区互动。
- **🛠️ 管理后台**：分类配置、题库维护与平台内容全生命周期管理。

## 🛠️ 技术栈

- **核心框架**：Vue 3 (`<script setup>`) + Vite 5
- **状态管理**：Pinia
- **路由管理**：Vue Router 4
- **网络请求**：Axios（全面接入真实微服务后端）
- **样式规范**：原生 CSS 变量系统，全面适配浅色 / 暗色主题

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 本地开发

```bash
npm run dev
```

本地服务启动后，访问 `http://localhost:5173` 即可预览。

### 3. 生产构建

```bash
npm run build
```

构建产物将输出至 `dist/` 目录。

## 📁 目录结构

```text
├── public/              # 静态资源与站点图标
├── src/
│   ├── api/             # 真实后端接口封装
│   ├── assets/          # 样式、图片与官方技术矢量图标
│   ├── components/      # 通用全局组件
│   ├── router/          # 路由配置与守卫
│   ├── stores/          # Pinia 状态管理
│   ├── utils/           # 工具函数与出卷算法
│   └── views/           # 页面视图（题库、考场、圈子、面试、后台等）
├── index.html           # 页面入口
├── package.json         # 依赖配置
└── vite.config.js       # Vite 工程配置
```
